# 🦷 OdontoSys

Sistema full stack de gestão para clínicas odontológicas, desenvolvido para centralizar processos de **agendamento, atendimento clínico e controle financeiro** em uma única aplicação.

## 🎯 Objetivo

O OdontoSys busca substituir controles dispersos em fichas e planilhas por uma solução integrada, facilitando o acesso às informações da clínica e apoiando a rotina operacional e gerencial.

## 🚀 Tecnologias

### Backend
- Java 21
- Spring Boot
- Spring Data JPA
- REST API

### Frontend
- React

### Banco de dados
- PostgreSQL

## ✨ Principais objetivos do sistema

- Centralizar dados da clínica em uma única plataforma.
- Organizar o fluxo de agendamentos e atendimentos.
- Apoiar o controle financeiro.
- Melhorar a integridade e disponibilidade das informações.
- Fornecer uma base para relatórios e tomada de decisão.

## 🏗️ Arquitetura

O projeto é dividido em frontend e backend, utilizando uma API REST para comunicação entre a interface React e a aplicação Spring Boot. A persistência dos dados é realizada em PostgreSQL.

```text
React
  ↓
REST API
  ↓
Spring Boot
  ↓
Spring Data JPA
  ↓
PostgreSQL
```

## 📌 Sobre o projeto

Este projeto foi desenvolvido como aplicação prática de engenharia de software, integrando conceitos de desenvolvimento backend, frontend, persistência de dados e modelagem de sistemas.
